# Student Task Manager

A simple console application written in C#. This is my educational project to practice and learn C# basics.

## Features
* **Add tasks:** You can add a new task and choose its priority (Low, Medium, High).
* **View tasks:** Shows a list of all your current tasks.
* **Remove tasks:** You can delete a task by typing its number.
* **Task limit:** The application has a strict limit of 10 tasks. You can check how much free space is left.

## What I learned in this project
* How to use `List<string>` to store and manage data.
* How to create an interactive menu using a `while` loop and `switch` statements.
* How to create custom data types using `enum` (for Task Priority).
* How to use `const` variables to set safe limits (Max 10 tasks).
* How to organize code using custom methods (functions).
